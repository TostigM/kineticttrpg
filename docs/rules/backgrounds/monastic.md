# Monastic Background

This file defines the 5-level branching tree for the Monastic origin, with mechanical benefits at each decision.

## Decision Keys

### Level 1
* `1` **Scholastic Order:** +1 Intellect.
* `2` **Vigil Order:** +1 Will.

### Level 2
* `.1` **Scriptorium:** Expert archive research and lore indexing.
* `.2` **Infirmary:** Expert stabilization treatment and herbal triage.

### Level 3
* `.1` **Meditative:** +2 to checks against fear panic and coercion.
* `.2` **Ritualist:** +2 to checks involving rites vows and sacred procedure.

### Level 4
* `.1` **Sheltering Hand:** Once per scene remove one minor debuff from an adjacent ally.
* `.2` **Focused Breath:** Once per scene reroll a failed Will based check.

### Level 5
* `.1` **Warden Prayer:** The first support skill each encounter grants +1 on the target next roll.
* `.2` **Ascetic Strike:** First successful melee hit each combat applies [Dazed]; after triggering this your next check this round is -1.
