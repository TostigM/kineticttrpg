# Urban Background

This file defines the 5-level branching tree for the Urban origin, with mechanical benefits at each decision.

## Decision Keys

### Level 1
* `1` **Trade Ward:** +1 Intellect.
* `2` **Backstreets:** +1 Agility.

### Level 2
* `.1` **Guild Trained:** Expert in one craft or profession; common item crafting downtime reduced by 25 percent.
* `.2` **Street Taught:** Expert urban stealth and rumor gathering.

### Level 3
* `.1` **Paper Trail:** +2 to checks involving records permits or contracts.
* `.2` **Alley Sense:** +2 to checks to evade pursuit in settlements.

### Level 4
* `.1` **Crowd Slip:** Once per scene ignore engagement penalties while moving through crowds.
* `.2` **Fast Talk:** Once per scene reroll a failed social check against a non hostile NPC.

### Level 5
* `.1` **Market Leverage:** Start each session with 1 leverage token (+2 on one negotiation check).
* `.2` **Ambush Instinct:** First attack from concealment each combat applies [Dazed]; if that attack misses generate +1 Heat.
